**Figure 1.** Overview of pramana. Training DCPs are characterized once, then explored through
LLM-guided rounds in which each design's analyst sees a draft knowledge base of the other
designs' results, a critic checks the analysts' claims against the evidence, and the LLM's
influence on run allocation is weighted by its measured prediction accuracy. A per-DCP noise
floor from perturbed reference runs separates real gains from tool sensitivity. Discovered
recipes are validated across designs (and simulated when they edit the netlist) before
distillation into a knowledge base with per-budget policies and step interactions, which is
compiled for LLM-based and deterministic flows and for other agents' formats, and evaluated
on unseen DCPs.
